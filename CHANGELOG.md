## 3.73 — file editing and repository polish

- **Rename files and folders**, including the extension, through the Git data API — three requests however many files are inside.
- **Commit message and description** on every commit: add, edit, delete, rename and upload.

- **Full-screen editor** with line numbers, wrapped code, and the commit controls pinned to the bottom.
- **Top repositories** on the home screen with real owner avatars, falling back to the owner's initial.

- Branch switching per repository; the branch chip sits on the repository and Files screens.
- Pull to refresh now really refreshes — the cache no longer answers a manual refresh.

- Pinned repositories removed from the home screen.
- One toast at a time instead of stacking.
